Hello and welcome

Welcome to the first web exercise! You will learn about HTML, a markup language that defines the content and structure of a web page.

Let's start with a simple exercise. On the left side there is some HTML and on the right there is the result. Can you see some pattern?

HTML 


<html>
    <head>
    </head>
    <body>
        A story with a random title</h1>
        <p>This is the story of a random character.</p>
    </body>
</html>

Result

A story with a random title

This is the story of a random character.

Congratulations! Level finished!

<html>, <head>, <body>, <p> and <h1> are called tags.
Most tags go in pairs, the opening one (e.g. <html>) and the closing one (e.g. </html>).

There are 3 fundamental tags:
<html></html>: we always start with the tag <html> (it announces that the rest will be html code)
and we close everything at the end with </html>.
<head></head> :contains metadata (i.e. data not readable on the web page but important for the web browser).
<body></body>: contains everything visible on the web page.

There are a lot of different tags that do different things.
Don't hesitate to look them up on internet!
For now we will focus on the body tag and leave the head one empty.
