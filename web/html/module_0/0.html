<html>, <head>, <body>, <p> and <h3> are called tags.
Most tags go in pairs, the opening one (e.g. <html>) and the closing one (e.g. </html>).

There are 3 fundamental tags:
<html></html>: we always start with the tag <html> (it announces that the rest will be html code) and we close everything at the end with </html>.
<head></head>: contains metadata (i.e. data not readable on the web page but important for the web browser).
<body></body>: contains everything visible on the web page.

There are a lot of different tags that do different things. Don't hesitate to look them up on internet!
